# Organic Maps / CoMaps maneuver icon table

Organic Maps (and CoMaps, a fork with the same routing engine and icons) never put the
maneuver in the notification text — only as the `largeIcon` glyph. Steer reads that glyph
and, previously, tried to guess the turn from its shape (the geometry classifier). That
guessing failed on Organic's arrow style and defaulted to **straight**, so a right turn
showed as "go straight" on the watch (reported by a cyclist who got lost).

The fix mirrors what made Google Maps reliable: a **baked fingerprint table** built from
Organic's own maneuver drawables, matched by nearest-neighbour signature instead of guessed.

## Where the icons come from

`CarDirection.getTurnRes(exitNum)` in Organic Maps is the authoritative maneuver → drawable
map. The drawables (white on transparent, rendered to the notification `largeIcon`) are:

| Organic maneuver | drawable | Steer Direction |
|---|---|---|
| GoStraight / NoTurn / StartAtEndOfStreet | ic_turn_straight | STRAIGHT |
| TurnLeft / TurnRight | ic_turn_left / right | LEFT / RIGHT |
| TurnSlightLeft / Right | ic_turn_*_slight | SLIGHT_LEFT / RIGHT |
| TurnSharpLeft / Right | ic_turn_*_sharp | SHARP_LEFT / RIGHT |
| UTurnLeft / Right | ic_turn_uleft / uright | UTURN_LEFT / RIGHT |
| ReachedYourDestination | ic_turn_finish | ARRIVE |
| ExitHighwayToLeft / Right | ic_exit_highway_to_* | RAMP_LEFT / RIGHT |
| Enter / Stay / LeaveRoundAbout, all exit_N | ic_turn_round, ic_roundabout_exit_N | GENERIC_ROUNDABOUT_RIGHT |

`mapping_table.png` shows every row visually (Organic icon ↔ Steer icon).

## Known limitation — roundabout exit number

Organic's roundabout icons are a **circle with the exit NUMBER inside** (`ic_roundabout_exit_1..12`).
We only receive the icon, not the exit number as data, and the watch has no numbered-roundabout
icon. So **every roundabout currently maps to the generic roundabout** — the watch says
"roundabout" (a big improvement over the old "straight"), but **not which exit**.
See `roundabout_decision.png`. A proper fix needs new watch icons (roundabout + digit) and a
reliable way to read the digit; tracked as future work.

## Regeneration

Assets: `android/app/src/debug/assets/om_maneuvers/` (debug-only, not shipped). Ground truth:
`OrganicGlyphs.LABELS`. The signatures in `ManeuverFingerprints.ORGANIC_TABLE` are generated by
`/tmp/gen_om_table.py` (replicates `IconConverter.pack` + `ManeuverClassifier.signature`).
`OrganicGlyphTableTest` verifies every entry matches its ground-truth Direction and that each
glyph resolves correctly by nearest-neighbour.
